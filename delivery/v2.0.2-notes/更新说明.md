# 映匣 (YingXia Player) v2.0.2 更新说明

> 本版本重点修复 2.0 在标准尺寸手机上视频列表退化为单列大图的问题，并包含 v2.0.1 的真机相册分享兼容性修复。签名证书与 v1.9.1 / v2.0.0 / v2.0.1 完全一致，可直接覆盖安装升级（**请勿先卸载**，以免清空本机加密保险箱）。

## 本次修复（v2.0.2）

- **恢复视频列表左右双列排列（上下滑动）**：将视频网格升级为 `ResponsiveVideoGridCells`，在 320dp–430dp 所有常见手机竖屏（含调大系统显示大小）下始终保持**左右两列**紧凑排布，同时在横屏与平板上继续自适应扩展至 3～4+ 列。
- **统一 16dp 页面边距与筛选栏间距**：恢复与 v1.9.1 一致的 `16.dp` 左右边距并微调筛选胶囊间距，解决 360dp 标准屏下「收藏」胶囊被裁切过窄的问题。

## 包含的 v2.0.1 修复

- **修复部分国产 ROM 系统相册「分享 → 映匣」被误拒**：兼容 `content://0@media/...`、`content://0@com.miui.gallery.open/...` 等多用户数字前缀 URI、`ACTION_SEND` 同时附带 `EXTRA_STREAM` 与 `clipData` 别名、以及 `*/*` 通用 MIME 类型，同时保留阻止自身私有 Provider 与非视频文件的安全防线。

## 安装包选择

- **`YingXia-2.0.2.apk`（推荐 · 零联网纯净核心版）**：`cn.yingxia.player`，Manifest 零网络权限、DEX 零同步/网络类，日常本地看片与隐私保险箱首选。
- **`YingXia-2.0.2-sync.apk`（可选 · 自托管同步扩展版）**：`cn.yingxia.player.sync`，可与核心版共存，额外提供自托管 Ktor 端到端加密同步与 HTTP 206 流式直播。
