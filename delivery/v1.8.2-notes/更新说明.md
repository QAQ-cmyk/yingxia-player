# 映匣 1.8.2 · 备份导入安全加固

[English](RELEASE_NOTES.en.md)

## 更新内容

映匣 **1.8.2** 为稳定性与安全边界小版本更新（完整包含 1.8.1 的整文件夹一键批量加密能力）：

- **备份导入增加 10 MB 流式大小上限**：手动恢复本地记录备份时改为分段流式校验读取，一旦超过 10 MB 立即中止并弹出清晰提示，避免误选大体积视频文件导致内存溢出或卡死。
- **备份读写移至后台 IO 线程**：备份导出、分享与导入的文件读写全面移至 `Dispatchers.IO`，避免阻塞界面线程。
- **CI 构建稳定性优化**：为 GitHub Actions 工作流补齐官方镜像与 Gradle 缓存（不改项目本地构建配置，保持零联网与 FOSS 可复现构建）。
- **从旧版升级**：使用与 1.8.1 / 1.8.0 / 1.7.x 一致的正式证书签名，**请直接覆盖安装，切勿先卸载**（卸载会删除加密保险箱）。

**验证记录**：适用于 Android 8.0 及以上。JVM 单元测试（25/25）、Android Lint（0 错误）、`scripts/check-apk-privacy.py` 零联网隐私校验（`PASS`）以及 Android 14（API 34）官方模拟器全量回归验证均已通过。
