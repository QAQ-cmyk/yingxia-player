# 映匣 2.0.0 · 极简 UI 重构、安全审计加固与双版本架构

[English](RELEASE_NOTES.en.md)

## 更新内容

映匣 **2.0.0** 带来全面架构与视觉升级，同时继续坚守**核心版永久零联网、零权限、纯本地私密**的设计原则：

- **极简 2.0 界面与交互重构**：
  - 全量移除高饱和粉紫配饰，统一采用冷灰白 + 岩板蓝（`#2563EB` / `#60A5FA`）与全面屏沉浸通透栏。
  - 底部导航精简为 **媒体库 | 文件夹 | 空间**（宽屏 `>= 600dp` 自动切换为侧边 `NavigationRail`），将「全部 / 在看 / 收藏 / 书签 / 历史」收拢进媒体库单行胶囊筛选栏。
  - 升级悬浮暗夜多选浮岛（支持播放、入箱、删除与更多操作）及可关闭的继续观看悬浮胶囊，统一播放页「影院黑」视觉与单行动作胶囊、内联书签跳转胶囊。
- **双变体隔离架构与可选自托管同步版**：
  - `YingXia-2.0.0.apk`（`offline` 默认核心版，`cn.yingxia.player`）：构建期物理隔离同步模块，APK 内**不含 `INTERNET`、`ACCESS_NETWORK_STATE` 权限，零网络/同步类字节码**。
  - `YingXia-2.0.0-sync.apk`（`sync` 自托管同步扩展版，`cn.yingxia.player.sync`）：可与离线版双开共存，对接自建 `:server`（Kotlin + Ktor），支持 HTTP 206 Range 远程流式播放、零知识端到端加密快照与书签同步，以及 SHA-256 校验的 `.vault` 密文冷备恢复。
- **性能与安全加固**：
  - Release 包启用 R8 代码压缩与资源裁剪，包体积缩减至约 4.4 MB。
  - 新增 Android Keystore 硬件绑定 **生物识别（指纹/面容）快捷解锁**（密码变更或新指纹录入时自动失效）、密码加密本地记录备份（`.yxbackup.enc`）及分享缓存自动覆写清理。
  - 自研零联网内存缩略图缓存替换网络加载链路，全页面补齐 `FLAG_SECURE`、扫描后台并发一致性及多项 UI 交互细节修复。
- **从旧版升级**：离线核心版 `YingXia-2.0.0.apk` 使用与 1.9.1 / 1.8.x / 1.7.x 一致的正式证书签名，**请直接覆盖安装，切勿先卸载，以免清空加密保险箱**。

**验证记录**：适用于 Android 8.0 及以上。`shared-protocol`（1/1）、`server`（1/1）、`app` 离线与同步单元测试（各 30/30）、双变体 Android Lint（0 错误）、Android 14（API 34）模拟器全量仪器测试（离线版 46 项中 45 通过 / 1 按 API < 29 条件跳过 / 0 失败；同步端到端测试 2/2 通过）以及 `scripts/check-apk-privacy.py` 对最终签名版 `YingXia-2.0.0.apk` 的零联网零备份红线校验（`PASS`）均已通过。
