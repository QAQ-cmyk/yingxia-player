# 映匣 (YingXia Player) v2.0.3 更新说明

> 本版本统一了竖屏播放页与首页媒体库的浅色/深色主题视觉衔接，并包含 v2.0.1（真机相册分享兼容）与 v2.0.2（标准屏左右双列视频墙）的全部修复。签名证书与历史版本完全一致，可直接覆盖安装升级（**请勿先卸载**，以免清空本机加密保险箱）。

## 本次优化（v2.0.3）

- **播放页二级界面跟随当前浅色/深色主题**：取消竖屏播放页强制全黑，保留顶部状态栏与 16:9 视频画面区纯黑沉浸显示，同时将下方的标题信息、快捷操作胶囊、时间书签、播放列表、底部工具弹窗以及底部系统导航栏图标统一改为跟随当前主题（浅色模式下为清爽白底 + 柔和板岩蓝高亮；深色模式下保持影院深色）。

## 包含的 2.0.x 近期修复

- **v2.0.2**：视频列表恢复为手机竖屏始终左右两列、上下滑动，统一 16dp 页面边距并优化筛选栏显示。
- **v2.0.1**：修复部分国产 ROM 系统相册「分享 → 映匣」被误拒（兼容 `0@media` / OEM 多用户前缀、`EXTRA_STREAM` + `clipData` 别名、`*/*` MIME 类型）。

## 安装包选择

- **`YingXia-2.0.3.apk`（推荐 · 零联网纯净核心版）**：`cn.yingxia.player`，Manifest 零网络权限、DEX 零同步/网络类。
- **`YingXia-2.0.3-sync.apk`（可选 · 自托管同步扩展版）**：`cn.yingxia.player.sync`，可与核心版共存，额外提供自托管 Ktor 端到端加密同步与 HTTP 206 流式直读。
