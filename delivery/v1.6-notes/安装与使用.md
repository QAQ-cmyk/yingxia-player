# 映匣 1.6.0：加密保险箱

本次交付为本地构建，尚未发布 GitHub Release。APK：`delivery/YingXia-1.6.0.apk`；versionCode 12，最低 Android 8.0。

## 安装

正式签名证书与原 `YingXia-1.2.1.apk` 相同，可直接覆盖升级正式版，保留应用数据。系统提示时允许所用文件管理器安装此来源的应用。

此前的 `1.5.1-debug` 属于调试签名，不能用本正式包直接覆盖。遇到“签名不一致”请停止，不要先卸载；先确认现有安装包来源并做好迁移。普通 JSON 备份只包含普通记录，不能备份加密保险箱。

## 加密视频

1. 进入「我的 → 加密保险箱」，创建至少 8 个字符的密码并确认保存风险。
2. 点「加密本地视频」选择视频。也可从首页视频菜单进入「移入加密保险箱」，或长按多选后点「加密」。
3. 保持应用在前台，等待加密与完整校验。系统要求移除原件时点击允许。只有状态变为「相册原件已移除」，该原件才不再显示在手机相册。
4. 解锁后可直接播放、拖动进度、调节倍速。退出或切到后台会锁定；页面限制截图与录屏。
5. 需要返回相册时点「恢复到相册 → 解密恢复」，文件保存在 `Movies/映匣恢复/`，加密副本仍保留。

取消系统移除授权会同时保留原件与加密副本，原件仍能在相册看到。之后可在保险箱点击「继续移除相册原件」。

完成加密移入后，会清除该视频在普通资料库中的收藏、进度和书签。普通「隐藏」功能仍然只是过滤列表，并不会加密。

**请记住密码。忘记密码、卸载应用或清空应用数据，可能导致保险箱视频永久丢失。换机或卸载前先恢复到相册。** 云相册、回收站及其他副本需要单独处理。

详细格式与扩展约定见 `docs/加密保险箱.md`。测试范围见同目录的 `测试记录.md`。
