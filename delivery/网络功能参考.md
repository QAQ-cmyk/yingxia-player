# 网络只用于同一 Wi-Fi 互传

映匣没有账号，也不上传观看记录或视频。1.1.0 至 1.2.1 曾内置 B 站网页，该功能已经删除。1.5.0 起也不再提供投屏和 WebDAV / 云端传输，已保存的 WebDAV 地址和密码会在升级后从本机偏好里清掉。

现在唯一会使用网络的功能是「我的 → 同一 Wi-Fi 互传」：两台都打开了这个页面的映匣，在同一个局域网里直接收发文件，文件写入 Movies/YingXia。没有映匣的服务器。离开页面后接收停止。清单里的 INTERNET、Wi-Fi 和附近设备权限是为这次局域网发现和传文件准备的，不是为了访问互联网服务。

应用不包含统计、崩溃上报或广告 SDK。`delivery/v1.*-notes/` 只保留当时的在线说明，不描述现在的应用。
