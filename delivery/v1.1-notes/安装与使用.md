# 映匣 1.1.0 安装与使用

## 安装或升级

将 `YingXia-1.1.0.apk` 发到 Android 8.0 或更高版本手机，点击安装。如系统要求，为当前文件管理器允许安装此来源应用。旧版映匣可直接覆盖安装，保留收藏、隐藏、书签和续播；不要先卸载。

打开后允许全部视频、部分视频（Android 14+），或拒绝权限后使用「打开本地视频」。本地播放器不需要联网。B 站页面需要网络和可用的 Android System WebView / Chrome；缺失时应用会提示启用或更新。

## 整理手机视频

1. 「文件夹 → 新建文件夹」输入名称，再通过系统选择器选择上级位置，例如 Movies。应用会在手机存储中创建真实目录。
2. 视频卡片的「⋮ → 移动到文件夹」选择目标；长按多选可批量移动。可在移动面板中直接新建目标文件夹。
3. 移动先复制并校验完整内容，再请求删除原件。安卓系统出现确认框时，允许删除原件才算完成移动。收藏、书签和续播会跟随成功移动的视频。
4. 「⋮ → 删除原文件」会真正从手机存储删除视频；批量删除先长按多选。请核对应用显示的文件名和系统确认框。这个操作不能在映匣内撤销。

取消移动过程中的删除授权时，原文件和已校验副本都保留，结果框会写明「未完成移动」。不要将副本当成失败后自动清理的临时文件。批量操作遇到取消或失败会停止，已完成的项目不会回滚。

移动期间保持应用前台，并留出至少一份目标视频的空闲空间；大文件复制和校验需要时间。强制关闭、系统杀进程、设备断电可能留下副本或未完成的目标文件，原件只在校验成功后才会进入删除步骤。本版不提供断点搬运和事务恢复。

目标支持系统提供的内部存储和 SD 卡目录；系统不允许选择的根目录、Android/data 等位置无法使用。暂不将云盘当作移动目标，不支持文件夹改名/删除。文件夹授权失效时重新选择相同父目录与名称即可恢复授权。Android 8–9 整理文件时还需允许写入存储。

「隐藏」仍只影响应用内显示，不移动、删除或加密原件。隐藏管理不设密码；恢复后记录保留。

## 本地 / B 站切换

首页顶部点击「B 站」进入官方网页；点击「本地」回到相册。在线页提供后退、首页、登录、粘贴链接/BV 号和网页设置。

「登录」打开 B 站官方登录页，账号信息在该网页内填写，映匣没有自建密码表单。登录状态由本机网页 Cookie 保存；「网页设置 → 清除网页登录状态」清除该状态，不影响本地收藏、书签。

当网页已经提供可播放视频地址时，会出现「网页内播放」。点击后可播放/暂停、拖动进度及全屏；返回网页可继续浏览。其清晰度和可访问范围由 B 站网页决定，DASH/Blob 等资源仍使用网站自己的播放器。网页工具与本地播放器的 A-B 循环、书签等功能相互独立。

默认启用页面广告过滤，隐藏已识别的广告卡片、推广条并阻止少量广告资源域名。可在网页设置中关闭。**不能保证完全无广告**，视频内口播、植入和网站更新后的广告不一定能过滤。不会解锁付费、会员、地区或其他访问限制。

网页出现 412 风控、验证码、要求登录或加载失败时，按官网提示操作、稍后刷新或切换手机/电脑版。网页登录、验证码和画质选项受网站及当前网络影响。应用进入后台会暂停网页视频；返回后手动播放。

## 本地播放操作

- 倍速：0.25 / 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 / 3 倍；长按临时 2 倍或偏好设置中的 3 倍，松手恢复，暂停时不自动播放。
- 左右滑动画面或拖动进度条定位；单击控制栏、双击播放/暂停。全屏左侧上下滑动调亮度，右侧调音量；工具面板也有按钮和滑块。
- 字幕支持内嵌轨道和 UTF-8 SRT/VTT；系统选文件后需手动继续播放。A-B 循环两端至少相隔 0.5 秒，睡眠到期仍暂停。
- 时间书签支持备注、编辑、删除和跳转；队列支持顺序、单集循环、列表循环。进入后台、拔出耳机或失去音频焦点暂停。
- 「我的」提供历史、书签、隐藏管理和播放/外观设置。

卸载、清空应用数据会清除应用内记录与目录授权，但不会删除相册文件。已删除或失去访问权限的视频保留关联记录，普通列表不再显示，来源重新可用时可恢复。

测试范围和已知限制见「测试记录.md」。
