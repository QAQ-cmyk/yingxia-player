# 源码与构建

## 所需环境

- JDK 17、Android SDK Platform 35、Build Tools 35.0.0、Platform Tools。
- Gradle Wrapper 8.13；Android Gradle Plugin 8.9.2；Kotlin 2.1.20。
- 最低 Android 8.0 / API 26，目标与编译 API 35。在 Android 16 / API 36 上另做兼容性检查。
- 首次构建需要网络下载依赖；本地播放不需要网络，B 站模式需要网络与可用 WebView。

解压源码到英文路径，如 `C:\Projects\YingXia`，用 Android Studio 打开。在根目录创建 `local.properties`，写入 `sdk.dir=C:/Android/Sdk`（替换为实际路径）。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest :app:assembleRelease
```

调试包输出至 `app/build/outputs/apk/debug/`；正式未签名包输出至 `app/build/outputs/apk/release/`。Windows 中文路径可能影响 JVM 测试类路径，建议使用英文路径。

## 设备检查

标准方式为 `:app:connectedDebugAndroidTest`；也可直接运行已经构建的设备测试：

```powershell
.\scripts\device-tests.ps1 -Serial emulator-5554 -Sdk C:\Android\Sdk
```

脚本安装调试 APK 和测试 APK，并运行 AndroidJUnitRunner。测试用本地合成 MP4，不依赖个人相册。正式包和调试包的签名不同；请使用专门的测试设备，不要为了运行测试卸载自己日常使用的映匣，否则应用内记录会丢失。

## 正式签名

交付 APK 已使用本项目独立签名，可直接安装。私钥和密码未放入源码 ZIP，也不在 Git 中。本机原项目 `.tools/signing/` 保留用于后续覆盖升级；应单独备份这两个文件，不要公开。

如已有项目所有者提供的签名材料：

```powershell
.\scripts\sign-release.ps1 -Sdk C:\Android\Sdk -KeyStore <私钥文件路径> -PasswordFile <密码文件路径> -Alias yingxia
```

密码文件为一行密码，不应把密码直接写在命令行。新开发者也可创建自己的签名，但不能用新签名覆盖原签名应用。

## 包含与排除

源码包包含 Kotlin 源码、资源、Room schema、构建脚本、Gradle wrapper、单元与设备测试、合成测试片、开发说明和交付记录。排除 SDK、JDK、Gradle 缓存、模拟器、构建产物、机器路径配置及签名材料。

接口扩展方式见「扩展接口.md」。真实测试范围见「测试记录.md」，不要将模拟器结果视为所有手机型号的验收。
