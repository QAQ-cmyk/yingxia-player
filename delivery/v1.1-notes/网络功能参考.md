# 在线模式参考与实现边界

2026-11-12 实现时检索并阅读下列 GitHub 资料。借鉴结构思路，未直接复制仓库实现或广告规则，也未引入第三方客户端二进制。

| 来源 | 参考用途 | 本项目实现 |
|---|---|---|
| [Abelliuxl/bilibili-web-client](https://github.com/Abelliuxl/bilibili-web-client) | 原生 WebView 容器、Cookie、UA、全屏和导航管理 | Kotlin/Compose 独立容器及官方网页登录入口 |
| [festoney8/bilibili-cleaner](https://github.com/festoney8/bilibili-cleaner) | 网页广告元素识别、动态页面适配 | 自写小范围 CSS 与 MutationObserver，不复制整套脚本 |
| [Biliverse/ADBlock](https://github.com/Biliverse/ADBlock) | 对比原生客户端代理过滤路线 | 未采用代理、证书安装或 protobuf 拦截 |

Android 官方依据：[WebView](https://developer.android.com/develop/ui/views/layout/webapps/webview)、[共享媒体修改与删除](https://developer.android.com/training/data-storage/shared/media)、[部分视频授权](https://developer.android.com/about/versions/14/changes/partial-photo-video-access)。

应用增加 INTERNET 权限，仅在线页使用网络；没有本地视频上传逻辑。网页没有 JavaScript 原生接口、文件访问、内容提供器访问或原生文件选择器。主页面只允许 HTTPS B 站域名和 b23.tv，拒绝非 HTTPS、伪装域名、用户名形式 URL 及非标准端口；资源可访问网站使用的媒体 CDN。SSL 错误中止，混合内容禁止，第三方 Cookie 关闭。

`bilibili-clean.js` 为可关闭的窄范围广告样式；`bilibili-player.js` 提供网页内播放按钮，只读取当前网页现有 video 元素的 HTTPS 地址，不调用隐藏接口、解析会员接口或更改账号权限。网站提供 Blob / MediaSource 时保持原网页播放器。网页独立播放器支持按钮、进度和 HTML5 全屏，受官网资源有效期和访问权限限制。

实测部分模拟器上的手机版显示为海外英文页面，Android 14 上显示中文；电脑版某些页面返回 412 风控。手机公开视频已实测播放和全屏；官方登录页已打开，但未输入账号、密码或短信码，因此不能宣称账号登录、验证码或登录状态跨重启已完整验收。

页面过滤不是完全无广告承诺。网站结构、网络、地区和 WebView 版本改变时需重新验证，尤其不能把移除网页推广条等同于去除视频内商业植入。
