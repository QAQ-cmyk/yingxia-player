# 映匣 2.0.1 · 修复部分国产系统相册「分享给映匣」误拦截

[English](RELEASE_NOTES.en.md)

## 更新内容

映匣 **2.0.1** 为热修复版本（完整包含 2.0.0 的极简 UI 重构、4.2MB 轻量瘦身、生物识别解锁、加密备份与双版本架构）：

- **修复真机相册「分享 → 映匣」提示「没有收到可读取的本地视频」**：
  - 兼容 MIUI / HyperOS / ColorOS / OriginOS / HarmonyOS 等系统多用户相册自动附加数字用户前缀的 URI（如 `content://0@media/...`、`content://0@com.miui.gallery.open/...`），同时继续严格拦截非数字伪造前缀及应用自身 `FileProvider` 路径；
  - 兼容系统相册在单视频 `ACTION_SEND` 中同时传递 `EXTRA_STREAM` 与不同别名 `clipData`、以及使用 `*/*` 通用 MIME 类型分享视频的场景；
  - 加固 `LocalMedia` 对 `0@media` 识别、部分 OEM `FileProvider` 列查询异常及视频轨元数据判定。
- **从旧版升级**：离线核心版 `YingXia-2.0.1.apk` 使用与 2.0.0 / 1.9.1 / 1.8.x 一致的正式证书签名，**请直接覆盖安装，切勿先卸载**。
