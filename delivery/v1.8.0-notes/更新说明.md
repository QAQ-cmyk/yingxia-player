# 映匣 1.8.0 · 完整中英双语界面与开源商店就绪

[English](RELEASE_NOTES.en.md)

## 更新内容

映匣 1.8.0 为整个应用带来了完整的 **简体中文 / English 双语支持**，并完成了面向开源安卓商店的纯净构建准备。

- **完整中英双语界面**　支持自动跟随系统语言（非中文系统默认显示英文，中文系统默认显示简体中文），覆盖 1.7.4 新增的相册分享、本次不记播放记录与播放中快速锁箱，也支持在「我的 → 播放与外观 → 语言」中一键切换，并适配 Android 13+ 系统应用级语言设置。
- **纯净开源分发准备**　新增 `fastlane/metadata/android/` 中英文商店元数据，并在构建配置中关闭了 APK 加密依赖块（`dependenciesInfo`），为提交 IzzyOnDroid / F-Droid 做好准备。
- **加密保险箱去重与批量移入大幅修复**
  - 修复跨相册分享 URI / `external` 与 `external_primary` / 恢复后再移入等场景下同一视频被重复复制出多份加密副本的问题（通过源 ID、规范化 URI 与文件大小 + SHA-256 摘要精准复用已有完好密文）。
  - Android 11+ 批量移入改为先完成全部加密与校验，再合并为**单次系统弹窗一次性移除全部相册原件**，且系统弹窗触发后台锁箱后不会丢弃待核对队列。
  - 新增「一键移除全部待处理原件」、旧版遗留重复副本「校验后一键清理」、恢复到相册可选「同时删除保险箱副本」、相册分享支持一步「加密并移除原件」，以及带缩略图、全选与「已在保险箱」标识的加密选择器。
- **修复与优化**　优化部分国产 ROM 删除原件后 `query()` 返回 `null` 的核对兼容性；修复了非中文界面下全屏亮度/音量手势图标判定问题，并适配中英文自动化 UI 与相册分享测试。
- **从旧版升级**　请直接覆盖 1.7.4 或旧版安装，**切勿先卸载**（卸载会删除加密保险箱）。现有保险箱视频、播放记录与密保问题均可直接沿用。

**安装与验证**　适用于 Android 8.0 及以上。JVM 单元测试（23/23）、Android 14（API 34）模拟器全量设备测试（33 项运行通过 + 1 项仅限旧版 Android 跳过，共 34 tests）、Release 构建、Lint 与隐私校验脚本（零联网权限、已关闭云备份与调试）均已通过。正式发布前建议在真机实测覆盖安装与中英文切换，并将实测机型与系统版本补充至此。
