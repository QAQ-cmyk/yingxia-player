# 映匣 1.0.0

## 安装

将同目录 APK 发送到 Android 8.0 或更高版本手机，点击安装。如系统要求，仅为当前文件管理器允许安装此来源应用。首次打开后选择允许访问全部视频、仅选择部分视频，或者拒绝后点击「打开本地视频」。无需登录或联网。

安装文件为 `YingXia-1.0.0.apk`。部分视频授权由 Android 14 及以上提供；Android 13 和更早版本按系统支持显示授权选项。多次拒绝后，可在「我的 → 播放与外观 → 管理系统相册权限」重新授权。

这是独立本地播放器，不是 B 站客户端。视频文件留在原来的相册或文件夹中。

## 常用操作

- 首页点击视频播放；顶部搜索名称或文件夹，排序可按日期、名称、时长和大小。文件夹、收藏和我的位于底部导航。
- 点击倍速按钮选择 0.25 / 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 / 3 倍速。播放中长按画面临时加速，松手恢复；长按速度在「我的 → 播放与外观」设为 2 或 3 倍。
- 左右滑动画面预览目标时间，松手跳转；也可拖动进度条。单击显示控制栏，双击播放或暂停。
- 点击全屏按钮横屏观看。全屏左侧上下滑动调亮度，右侧调音量；播放工具里也有滑块。左侧锁形按钮防止误触，解锁后恢复操作。
- 播放工具提供字幕、A-B 循环、时间书签、睡眠定时。字幕支持内嵌轨道和 UTF-8 SRT/VTT，加载外部字幕后需要点击播放继续（打开系统文件选择器会暂停视频）。
- A-B 循环先在起点设置 A，再播放或快进到终点设置 B。B 至少晚 0.5 秒；到达 B 返回 A。睡眠计时结束仍会暂停。
- 书签可以备注、编辑、删除或点击跳转。播放列表支持顺序播放、单集循环、列表循环。重新打开可续播，也可以从头播放。
- 视频卡片长按进入多选，可批量隐藏、收藏或加入队列。「我的 → 隐藏管理」中恢复显示。

## 数据与边界

隐藏仅影响映匣内显示，不移动、删除或加密原视频，其他相册应用仍能看到原件，隐藏管理不设密码。恢复后保留原收藏、书签和续播记录。

卸载或清空应用数据会清除所有设置和关联记录，不会删除相册原视频。文件删除、权限撤回或存储设备移除后可能无法播放，记录会保留。格式支持取决于手机解码能力；优先使用 MP4/H.264/AAC。

切到后台、拔出耳机或失去音频焦点时暂停，不提供后台音频播放。无联网权限、无广告、无服务器；如系统文件提供方自身来自云盘，其本地可用性由系统提供方决定，文件选择器设置为仅本地。

实际检查范围、已知限制详见「测试记录.md」。界面截图使用专门制作的测试视频，不附带个人相册内容。

后续更新应使用同一签名且提高版本号，直接覆盖安装以保留记录。不要为普通升级先卸载应用。签名私钥保存在本机项目的 `.tools/signing/`，未包含在交付源码 ZIP 中，需由项目所有者单独保管。
