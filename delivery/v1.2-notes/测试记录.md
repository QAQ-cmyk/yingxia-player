# 映匣 1.2.0 测试记录

日期：2026-11-12。交付版本：versionName 1.2.0 / versionCode 3，最低 API 26，目标 API 35。

## 本次改动

- 网页自动唤起 App 不再产生连续的「此链接不能在应用内打开」提示。已知的用户点击转成应用内 HTTPS 页面，未知或后台请求安静拦截。
- 应用提供「推荐 / 搜索 / 账号」导航，移除地址栏、重复网页导航和旧二层播放面板。推荐卡片及 `data-aid` 搜索卡片在同一 WebView 中进入视频。
- 复用网页原有 video 元素，原位提供播放/暂停、进度、八档倍速和全屏。页面首次可见时开始适配，完成加载时幂等补充，减少图片加载慢时露出原网页入口的问题。
- 视频页有返回按钮及没有网页历史时回到首页的退路。保留本地视频、真实目录、移动、删除、隐藏及学习工具。
