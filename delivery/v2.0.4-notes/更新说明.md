# 映匣 (YingXia Player) v2.0.4 更新说明

> 本版本新增**长按倍速自由选择（`1.5× / 2× / 2.5× / 3× / 4×`）**及**长按后左右滑动实时切档**功能，并包含 v2.0.1～v2.0.3 的全部体验优化。签名证书与历史版本完全一致，可直接覆盖安装升级（**请勿先卸载**，以免清空本机加密保险箱）。

## 本次新增（v2.0.4）

- **5 档长按临时加速可选（`1.5× / 2× / 2.5× / 3× / 4×`）**：
  - 在播放页点击右上角 **倍速胶囊（如 `1×`）** 即可直接切换「长按临时加速」默认档位（普通视频与加密保险箱视频均支持）；
  - 在 **空间 → 设置** 中同样提供 5 档选择，并完整纳入本地加密备份与同步快照。
- **长按后左右滑动实时切档**：长按画面触发临时加速后，手指不松开即可左右滑动在 `1.5× ～ 4×` 之间实时切换档位（伴随轻触觉反馈），松手即恢复原播放速度，且当前播放速度更快时不会降速。

## 包含的 2.0.x 近期更新

- **v2.0.3**：竖屏播放页二级界面跟随当前浅色/深色主题，保留视频画面纯黑沉浸观影。
- **v2.0.2**：视频列表恢复手机竖屏始终左右双列、上下滑动，统一 16dp 边距。
- **v2.0.1**：修复国产 ROM 系统相册「分享 → 映匣」误拒问题。

## 安装包选择

- **`YingXia-2.0.4.apk`（推荐 · 零联网纯净核心版）**：`cn.yingxia.player`，Manifest 零网络权限、DEX 零同步/网络类。
- **`YingXia-2.0.4-sync.apk`（可选 · 自托管同步扩展版）**：`cn.yingxia.player.sync`，可与核心版共存，额外提供自托管 Ktor 端到端加密同步与 HTTP 206 流式直读。
