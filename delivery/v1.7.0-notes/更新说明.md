# 映匣 1.7.0 · 本机密保

解锁保险箱后，可以自愿设置三道密保问题。忘记密码时，在同一台手机上答对全部三题，即可设置新密码。原视频、名称、续播和书签保留，重设后可重新开启密保。1.6.1 用户可以直接覆盖安装，再用原密码解锁并设置。

密保只在当前安装中有效。答案和密码不以明文保存。未提前设置密保的旧保险箱，忘记密码后无法通过本次更新补救。卸载或清空数据会删除箱内文件。

**English** · Unlock the vault to optionally set up three recovery questions. Answer all three on the same phone to reset the password and retain your videos, names, progress and bookmarks. After resetting, you can set up recovery again. Install over 1.6.1 and unlock with the original password to enroll an existing vault. Recovery cannot reconstruct an uninstalled vault or unlock a previously unenrolled one without its password.
