# 在线模式参考与实现边界

2026-11-12 实现时检索并阅读下列 GitHub 资料。借鉴结构思路，未直接复制仓库实现或广告规则，也未引入第三方客户端二进制。

| 来源 | 参考用途 | 本项目实现 |
|---|---|---|
| [Abelliuxl/bilibili-web-client](https://github.com/Abelliuxl/bilibili-web-client) | 原生 WebView 容器、Cookie、UA、全屏和导航管理 | Kotlin/Compose 独立容器及官方网页登录入口 |
| [festoney8/bilibili-cleaner](https://github.com/festoney8/bilibili-cleaner) | 网页广告元素识别、动态页面适配 | 自写小范围 CSS 与 MutationObserver，不复制整套脚本 |
| [Biliverse/ADBlock](https://github.com/Biliverse/ADBlock) | 对比原生客户端代理过滤路线 | 未采用代理、证书安装或 protobuf 拦截 |

Android 官方依据：[WebView](https://developer.android.com/develop/ui/views/layout/webapps/webview)、[共享媒体修改与删除](https://developer.android.com/training/data-storage/shared/media)、[部分视频授权](https://developer.android.com/about/versions/14/changes/partial-photo-video-access)。

应用增加 INTERNET 权限，仅在线页使用网络；没有本地视频上传逻辑。网页没有 JavaScript 原生接口、文件访问、内容提供器访问或原生文件选择器。主页面只允许 HTTPS B 站域名和 b23.tv，拒绝非 HTTPS、伪装域名、用户名形式 URL 及非标准端口；资源可访问网站使用的媒体 CDN。SSL 错误中止，混合内容禁止，第三方 Cookie 关闭。

`bilibili-clean.js` 为可关闭的窄范围广告样式。1.2.0 的 `bilibili-player.js` 在手机版现有 video 元素上启用控件，并在原视频区域加入播放、倍速和 HTML5 全屏；不复制媒体 URL、不另建播放器或二层播放页。电脑版保留原站播放器。不调用隐藏接口、解析会员接口或更改账号权限。

真实页面的推荐卡片使用 `m-open-app` 自定义组件。脚本在其唤起 App 之前，接管可识别的 HTTPS 视频链接与 `universallink`；搜索卡片则校验 `data-aid`，转换为对应视频地址，在同一 WebView 内打开。当前视频的播放按钮直接控制原元素。原生 `BilibiliSource.appLink/appNavigation` 是补充路由：转换已知视频、分 P、空间、搜索、番剧链接，忽略后台探测、重复当前视频和未知协议，不执行外部 Intent，不为每次探测排队弹提示。页面没有原生 JavaScript 桥接。底部导航由应用提供，页面的重复页头、App 推广入口与旧浮动播放器入口被移除。

实测手机版首页及搜索显示中文，部分视频详情由官网返回英文内容；电脑版某些页面返回 412 风控。公开视频已实测播放和全屏；官方登录页已打开，但未输入账号、密码或短信码，因此不能宣称账号登录、验证码或登录状态跨重启已完整验收。页面及结果可能随网络、站点状态变化，实际版本的测试边界见交付测试记录。

页面过滤不是完全无广告承诺。网站结构、网络、地区和 WebView 版本改变时需重新验证，尤其不能把移除网页推广条等同于去除视频内商业植入。

## 1.2.1 账号返回规则核对

2026-11-12 核对了 B 站实际发布的 [通用登录页](https://passport.bilibili.com/login)、[手机登录页](https://passport.bilibili.com/h5-app/passport/login) 和 [账号中心](https://account.bilibili.com/account/home)，以及它们加载的官方脚本：

- [通用登录组件](https://s1.hdslb.com/bfs/static/2233-monorepo/passport/static/js/async/942.4a120455.js)：手机访问转入 H5 登录并保留查询参数；已有登录状态时使用 gourl / goUrl、来源页或默认首页决定返回地址。
- [手机登录组件](https://s1.hdslb.com/bfs/static/2233-monorepo/passport-h5/static/js/async/3368.208152d6.js)：创建页面时检查登录状态，已有会话会在显示表单前返回，gourl 是明确的返回位置。
- [账号中心组件](https://s1.hdslb.com/bfs/static/2233-monorepo/account/static/js/index.fdd38298.js)：未登录时将账号页地址编码到 gourl，再前往 passport。

本项目为账号入口明确设置官方账号中心返回地址，避免通用登录页把人带回推荐/视频。真实未登录页面验证与受控已登录回归分别记录，不将模拟会话当作实际账号验收。没有收集、读取或代填用户的密码、验证码、登录 Cookie。

同日检查[官方手机登录样式](https://s1.hdslb.com/bfs/static/2233-monorepo/passport-h5/static/css/async/3368.f30b2556.css)，其 `.explain-tips` 使用绝对底部定位；在短 WebView 中观察到说明文字覆盖密码入口。独立静态样式把该段恢复为正常文档流，仅精确用于手机登录页，保留官方控件、协议文字与行为，不涉及账号数据。
